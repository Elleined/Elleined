# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0.0| :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an email to the repository maintainer. All security vulnerabilities will be promptly addressed.

Please do not report security vulnerabilities through public GitHub issues. Instead, report them privately via email.

Once you have submitted a vulnerability report, you should receive a response within 48 hours. If the vulnerability is accepted, we will coordinate a fix and release schedule with you.
