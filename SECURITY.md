# Security Policy

## Supported Versions

Since this repository is just a GitHub profile README and does not contain application code or releases, all versions of the "code" (the README itself) are considered the current version.

| Version | Supported          |
| ------- | ------------------ |
| `main`    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this repository, please send an e-mail to the repository owner or open an issue outlining the concern (though since it's just a README, vulnerabilities are unlikely).

Please do not report security vulnerabilities through public GitHub issues if they expose sensitive information, although for this profile README repo, public issues are generally fine.
